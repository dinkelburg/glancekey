# Security

GlanceKey types your login password and approves `sudo`, so security problems matter most. Please report them privately, not in a public issue:

- on GitHub: **Security › Report a vulnerability** in this repository, or
- by email: ruben@dinkelworks.nl

Say what you found and, if you can, how to reproduce it. You'll get a reply as soon as possible, and the problem stays private until a fix is out.

This covers the iPhone app, the Mac app, the Linux program and the relay at relay.glancekey.com. The README's [How it stays safe](README.md#how-it-stays-safe) describes what GlanceKey protects against; for example, the relay isn't trusted, so a way for it to unlock or approve something on its own is a security problem. Fixes go into the latest version: the App Store, https://www.glancekey.com/download and the Homebrew tap.
